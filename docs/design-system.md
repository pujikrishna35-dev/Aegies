# Aegis Overseas Design System

## Brand Colors
- **Primary Burgundy/Wine**: `#8A1538` (`rgb(138, 21, 56)`)
- **Deep Navy / Slate**: `#0B132B` / `#1C2541`
- **Warm Gold Accent**: `#D4AF37` / `#C59B27`
- **Backgrounds**: Soft ivory `#FAF9F6`, pure white `#FFFFFF`, and slate `#0F172A`

## Typography
- **Headings & Body**: `Inter`, `Outfit`, `-apple-system`, `sans-serif`
- **Handwritten Signature/Accents**: `Caveat`, `cursive` (for trust stats, notes, quote accents)

## Interactive Elements
- **Flight Path Motion**: Diagonal trajectory climbing along the red accent curve (`flyAlongRedLine`).
- **Cards**: Soft drop shadows (`shadow-sm`, `shadow-md`), subtle borders (`border-slate-100`), hover lift (`hover:-translate-y-1 hover:shadow-xl`).
